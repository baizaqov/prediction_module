# Бизнес-правила

Каталог правил, извлечённых из постановки. Правила, отсутствующие в источнике, **не добавлялись**.
Пометки — см. [overview.md](overview.md).

**Обозначения места контроля:**
`UI` — клиентская форма · `API` — контроллер/валидация запроса · `DOMAIN` — доменный слой/движок расчёта ·
`AUTHZ` — слой авторизации · `DB` — ограничение целостности хранилища · `SEED` — миграция/наполнение справочника ·
`CFG` — конфигурация среды.

**Статус правила:** `ГОТОВО` — формулировка однозначна, можно реализовывать · `БЛОКИРОВАНО` — реализация невозможна
до ответа на связанный вопрос.

### BR-028 · Формула интегрального индекса
| | |
|---|---|
| **Правило** | `интегральный_индекс = SUM(балл_фактора × вес_фактора) / N_оценённых` |
| **Источник** | §4 |
| **Контроль** | `DOMAIN` |
| **Edge cases** | Делитель — **число оценённых факторов**, а не сумма весов: при полном заполнении каталога бруцеллёза максимум индекса ≈ `4 × 123 / 46 ≈ 10,70`, минимум `0`. ### BR-029 · Формула полноты

|---|---|
| **Правило** | `полнота = N_оценённых / N_панели` |
| **Источник** | §4 |
| **Контроль** | `DOMAIN` |

| **Статус** | `БЛОКИРОВАНО` (`Q-004`) |

|---|---|

RT-факторы принадлежат разным ролям (17, 18 — КВКН; 21, 24 — МИО; 31 — КСЭК), значит триггер может сработать от оценки любой роли |
